## 1. 本轮目标

上一轮已经完成教材原图视觉语义 gate 和第 2 页动画时序修复，但仍留下四个视觉问题：确定性 SVG 留白过多、图内标题与页面标题重复、窄屏标题/内容接近重叠、图片与宽面板同页时信息密度过高。本轮建立通用 SVG/模板布局契约，并用完整 10 页成片验证，不能用单页 `--only` 结果替代。

## 2. 已完成的代码改动

- 确定性 SVG 的 `viewBox` 改为按各类图形实际几何边界生成；长流程仍扩展画布，不裁末节点。
- `VisualSpec.title` 继续保留为无障碍 `<title>`，但不再绘制为图内可见标题。
- 模板对含图片页面输出 `t2v-has-visual`；图片与 comparison/table/flow/activity/quiz/bar 等宽元素同页时输出 `t2v-visual-with-wide`。
- CSS 按可用视口分配图片高度；1366×768 下对“图 + 宽元素”收紧间距和内边距，并把完整内容组有限上移到安全区内。
- 新增回归测试，覆盖紧裁 `viewBox`、无障碍标题保留、可见重复标题禁止、图片页密度 class 和普通图片页不误降级。

## 3. 完整 10 页复核方法与结果

由于先前 r18/r19 的 ignored 产物不在当前机器，本轮没有伪造或覆盖旧 run，而是创建新的 ignored development bundle：`.local/research_runs/visual-layout-contract-r20/`。输入复用已保存的 10 页 timed storyboard 与 SAPI 音频，并在第 2 页通过正式 compiled-visual/P0 binding 接入一个四节点确定性 SVG；事件在本段 4.368 秒触发。

- 完整 10 页 HTML：模板确定性渲染 `10/10`，未使用 `--only`。
- 1920×1080 layout QA：全部页面 PASS。
- 1366×768 layout QA：全部页面 PASS；第 2 页最后一项底边为 699px，低于 704px 硬失败线。
- 页面 2 事件检查：触发前无图；触发后 SVG 正常出现；后续原有四步流程完整出现。SVG 内没有重复可见标题，四个节点和箭头均可读。
- 完整无声视频：H.264，1920×1080，实际 231.4 秒。
- 有声成片：H.264 + AAC，实际 229.88 秒。
- 人工可见性检查：查看全部 10 页中点 contact sheet，并额外查看第 2 页事件前、SVG 出现后、底部流程出现后三个关键帧；未发现裁切、重复标题或错误图片进入。
- 全量自动测试：`510 passed`。

## 4. 明确没有完成或不能宣称的事项

- 本轮是布局回归，不是新的 Track A/Track B 正式实验；没有运行服务器批量实验，也没有更新任何论文效果统计。
- 当前机器没有 LLM 凭据，因此没有重新调用自动视觉规划模型；使用的是显式、可审计的确定性 VisualSpec。
- 冻结教材原图 `fig7-6` 在本轮重建中仍因缺少当前 run 的视觉语义 ACCEPT 记录而 fail closed；本轮没有绕过 gate。完整成片用于验证生成 SVG 布局，不代表教材原图 P0 条件重新通过。
- layout QA 仍会报告部分非阻塞历史 warning（例如安全区包围盒和第 6 页几何重叠提示）；本轮没有把这些 warning 改写为零，也没有声称它们属于实验 gate 通过。
- 人工检查由 Codex 执行，属于工程视觉复核，不是双人盲标、gold adjudication 或用户最终验收。

## 5. 后续建议

1. 恢复正式 Integrated AB 单课运行时，继续使用新的 run ID，并重新生成与该 run 绑定的视觉语义审核记录；不得复用本轮布局回归 bundle 充当正式实验产物。
2. 在服务器批量前，先由人观看一遍有声成片，重点核对字幕、语音、事件语义和第 6/8 页现存非阻塞 warning。
3. 若继续降低 warning，应优先修改全局 safe-area 测量与 fit-scale contract，并对全部 10 页回归；不要增加 lesson_002 专用 CSS selector。
