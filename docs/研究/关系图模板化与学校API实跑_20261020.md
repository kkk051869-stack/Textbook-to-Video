已有深蓝学术主题、页面模板和流程/比较等组件，继续复用。此次重点是把教学关系表达清楚：模型确定节点、连线、重点与依据，程序决定位置、文字换行、尺寸和颜色。场景插画可后续走 ecnu-image，本轮关系图没有调用文生图接口。

手工改稿用于确定目标外观，不能证明自动链路已达到同一水平；几何检查通过不能证明图意正确。模型自动选型也尚未验收，r5 的三类模板来自事前设计计划。

## 任务合同

- 目标：把三张手工设计候选的关系表达转成可复用组件，用学校 ecnu-plus 输出结构化内容并实际渲染。
- 允许修改：关系图组件、现有视觉资产编译与 P0 自动视觉规划的接入、produce 的主题参数传递、预览脚本、相关测试及本文。
- 禁止修改：冻结数据、gold、实验定义、A 归档、旧运行产物与服务器代码。密钥不进入任何版本化文件。
- 输入：既有区块链课程第 2、4、5 页的讲稿、标题与原有可见文字；不使用 gold。主题沿用 dark-blue-academic。
- 验收：真实模型输出落盘，图可渲染，1600×900 与 1366×768 的文字几何检查，实际看图；定向/全量回归、关键静态检查。
- 停止条件：模型补充无依据内容、图意偏离或超出布局预算时保留失败，修订后用新目录再试。

## 已实现

1. 新增 `src/textbook2video/research/relationship_visuals.py`，支持三类关系：多节点参与、输入合并/输出分流、单向转换。模型给出 nodes、edges 和原文引用，程序决定坐标、节点高度、换行与主题。
2. 固定字号下按中文/英文宽度估计换行；内容超过节点或列预算时报错要求拆图，不截断、不无限缩字。连线从节点边缘出发，标签尝试避让节点及已有标签。
3. 源文片段必须精确匹配。底部约束说明也必须是源文中的连续原句；不存在的手续费说明会被拒绝。此检查只证明引用存在，不能证明模型的释义或每条连线正确。
4. 新增 `kind=relationship` 作为增量 VisualSpec 方言。既有资产编译 CLI、P0 自动规划和 produce 可消费新图；produce 将实际页面主题传给编译器。旧平面图规格继续使用原渲染器。
5. `plan_relationship` 支持教学目标与预先声明的模板类型；模型未遵循类型时拒绝。原始模型响应先保存，再校验，不逐图手改 JSON。
6. 新增 `scripts/preview_relationship_visuals.py`。输入 storyboard 与页码，真实调用学校 API、编译资产、生成页面和两档截图，记录状态、源文件 hash、原始响应与最终 VisualSpec。

### 提交前独立复核与修复

独立只读审查发现两项初始测试没有覆盖的问题，均在发布前修复：

1. 长数值如 `12345678901234 BTC` 原先会以 44px 单行绘制而溢出。现按可用宽度换行并计入节点高度预算，放不下则拒绝；二次复验发现 `W×18` 等宽字母仍可能超界，已收紧非窄字符估宽，同时补齐列标题换行和主标题预算。新增 Edge 数字/宽字符实测边界回归。
2. P0 自动规划曾把 `generation_prompt` 拼入允许的原文范围，使上一模型生成的虚构指令可能被当作 evidence。现只允许 narration proposition 本文，不把生成指令当作原文；新增 prompt 伪证据反例并确认不输出成功计划。

这两项修复不代表模型内容已可免人工审查，尤其“引文存在”和“图意正确”仍必须分开判断。

## 本机复现

在仓库根目录执行；先将本机用户级 ECNU 环境变量导入当前进程。不要把密钥值写在脚本中。

```powershell
foreach ($name in @('ECNU_API_KEY','ECNU_BASE_URL','ECNU_DEFAULT_MODEL')) {
  [Environment]::SetEnvironmentVariable(
    $name, [Environment]::GetEnvironmentVariable($name, 'User'), 'Process'
  )
}
.\scripts\check_research_g0_starter.ps1 -Mode development -AllowDirty -RequireRendering -RequireLLM
.\.venv\Scripts\python.exe scripts/preview_relationship_visuals.py `
  --storyboard '<existing-storyboard.json>' `
  --segments '2,4,5' `
  --layouts 'peer_network,split_merge,one_way' `
  --output-dir '.local/relationship_api_preview/<new-unique-attempt>' `
  --model ecnu-plus
```

原始 storyboard 与图片不是此文档的内嵌附件；跨机器复现须提供该输入包及对应 hash。不存在的输入不能用示意内容替代。
