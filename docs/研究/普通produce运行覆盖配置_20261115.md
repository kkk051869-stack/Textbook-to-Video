# 普通 produce 的运行覆盖配置

保留普通默认值，通过本次进程环境变量覆盖；不修改研究方法与 Prompt。

```powershell
$env:T2V_VISUAL_AGENT_MAX_ITERATIONS = '3'
$env:T2V_RQ2_MAX_REPAIR_ROUNDS = '3'
$env:T2V_RQ2_REPAIR_DEADLINE_SEC = '300'
$env:T2V_MIN_FOCUS_BUDGET_PER_SEGMENT = '3'
$env:T2V_MAX_FOCUS_DURATION_SEC = '4'
# 在原有 produce 命令中使用 --max-generated-visuals 0
```

`0` 表示全部有效、尚未物化的 generate 任务；不是跳过生成。其他非负整数仍表示任务上限。未明确决定、拒绝、不确定或已物化需求仍按原规则处理。

Visual Agent 的 iterations 是总尝试轮数（包括首次，最多5），Proposed repair rounds 是首次之后的最大修正次数。重复错误、语义拒绝和现有提前终止仍有效，不保证耗尽全部轮次。Proposed 的300秒是现有修正循环总期限；不改变底层正在进行的请求的超时机制。

现有资产接口每个生成任务接收一张资产；所有需求分别执行，不用单次资产数量截断整课需求。多资产合成接口未在本次扩展。

focus 预算取现有局部讲解单元数与指定最低预算的较大值；4秒是持续时间上限，仍受对应旁白窗口约束。配置不会自动拆分模型联合选择，也不保证消除范围过宽的选择。

生成任务预算写入 selection 的 generated_visual_budget；RQ2 报告保存实际 repair rounds 和 deadline；动态事件保存实际持续时间。允许继续使用或提高预算均不表示教学正确性通过。
