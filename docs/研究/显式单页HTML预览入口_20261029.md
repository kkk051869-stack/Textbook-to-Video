## 用法

在仓库根目录，使用本工作树src与已验证的Python：

```powershell
$env:PYTHONPATH = "$PWD\src"
$env:LITELLM_LOCAL_MODEL_COST_MAP = 'True'
& .\.venv\Scripts\python.exe -m textbook2video.cli preview-local path\storyboard.json --segment 3 --output .local\my-new-preview
```

`--segment`是保存页面的ID，不是数组下标；仅处理所选一页。输入必须是已有局部合成流程保存的完整storyboard.json及images/、资产清单。输出目录必须不存在。可显式使用 `--theme dark-blue-academic`、`--browser msedge`。

默认 `--policy development` 只生成待复核工程预览，记录semantic_review=NOT_REVIEWED、human_review=NOT_REVIEWED、new_visual_alignment=NOT_VERIFIED，不提升原资产审核状态。`--policy strict` 复用storyboard教材图语义门禁及原revision的严格审核和hash绑定；缺教材图审核、资产审核或可核对的原revision时拒绝，不能靠工程预览标志放行。没有自动请求审核的fallback。
