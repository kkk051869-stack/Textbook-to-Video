# 联合讲解动作接入普通 produce

2026-11-13，当前工作分支 codex/joint-visual-planning-spike-20261113。本轮完成生产接线，未启动新教材生成、真实模型、TTS 或视频录制。

## 普通入口的实际行为

普通 `produce` 从 PDF/DOCX 教材新建课程时，默认使用以下路径，无须增加策略开关：

教材解析 → 原有教学计划 → 联合规划页面、讲解动作与旁白 → 既有视觉准备及页面保全 → 每个动作独立配音并测量 cue → 动作焦点事件 → 原有 Renderer / 录制 / 合成。

联合规划直接产出已有 Storyboard 的 elements，在页面上增量保存 teaching_actions、visual_relations 与生产版本元数据。每个动作包含旁白、精确来源引文、当前 focus、必要关系及 background。script.txt 和页面 narration 由动作顺序确定性派生，避免再生成一版不一致的讲稿。工程动作 ID 不冒充冻结研究命题标注。

程序负责页 ID、动作 ID、已有原生子对象 ID 映射、文件和 cue 校验；模型负责教学内容及关系组织。没有新增独立 Storyboard、动画系统或研究 Schema。当前支持原生文本、步骤、对比面板、表格及已提供目录中的教材图片；不声称已经增加通用 SVG 自动生成能力。

原文按句段分块请求，每块保存提示与原始响应；引用、对象或结构无效则明确失败，不自动修改语义或无限重试。记录模型、Prompt hash、来源块 hash；可定位引文不等于语义已经独立审核。

## 音频与动态事件

run_tts 对联合页面使用完整动作旁白作为一个实测语音单元，多句话不会被再次拆成多个不对应的动作。音频复用要求 cue 文本和动作一一一致，时长必须覆盖整页实测音频。

timing 根据动作 cue 生成已有 timeline/animations，焦点在动作起点后约0.12秒启动，到动作结束解除；这是动作级近似，不是词级强制对齐。不需要强调时允许空 focus。重算会重新生成本页事件，不保留旧词面事件或旧绑定焦点；首次整元素 focus 自带显示，不与同目标入场事件重叠。

联合页面不会被后续默认视觉准备重建为仅标题页。视觉准备必须保全动作及对象引用。Proposed 不重复改写联合规划焦点；如果对这种页面要求 rq2_audit，报告明确记录 NOT_RUN 和实际 binding_source，不将其计为 Proposed v1.3 的效果。

## 兼容边界

- 新教材的普通 PDF/DOCX produce 默认进入联合规划；内部构件参数用于区分生产与历史研究调用，不增加用户模式选择。
- P0 研究分支、已给定讲稿和旧分镜的恢复保持已有输入语义，不擅自重写冻结旁白。
- 保存的联合分镜重新加载后仍按 teaching_actions 读取配音 cue 和重建事件。联合页面的局部配音更新暂要求整页及对应 cue 一起重建，不接受缺少匹配 cue 的旧音频。
- RQ1、Proposed 核心算法、素材审核及来源/hash 门禁不在本轮修改范围内。现有素材获取功能继续运行，不能把原生组件联合规划当成 RQ1 或新图生成成功。
- 依赖当前工作树之前已有的原生子对象 ID、表格 DOM 和焦点样式支持；本轮未覆盖这些既有未提交修改。
