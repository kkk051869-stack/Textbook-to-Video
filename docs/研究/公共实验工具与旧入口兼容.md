## 公共工具的职责

- `experiment_support.freeze_experiment_inputs`：以新文件方式固定显式列出的来源、
  命题、候选对象、配置、源码/Prompt 文件的路径和 SHA-256，并记录方法及版本。
  它固定文件引用，不复制大体积素材；需要独立副本时使用已有 `snapshot.freeze_case`。
- `verify_experiment_inputs`：检查引用文件的字节；传入事先保存的 manifest SHA-256
  才能同时发现配置/方法元数据被改写。它不替代正式 `experiment_config/run_manifest`
  的数据隔离、预检和访问审计。
- `candidate_pool`：继续构造、校验和合并候选池，并检查四种结果覆盖。历史 schema、
  输出字段、覆盖策略保留；复用公共文件冻结和校验步骤。
- `validate_binding_references`：验证来源引用、命题 ID 和选定对象 ID，不修改任何
  方法选择/拒绑/失败状态，也不把 ID 有效等同于语义支持。
- `collect_event_evidence`：按事件关联方法决策、绑定、planned、compiled、runtime
  与 rendered 记录，保留未匹配和无 ID 记录；重复事件 ID 明确报错。执行、抽帧和
  最终可见性是不同层，`executed` 不会自动变成画面通过。
- `index_event_records`：现有 RQ3 和旧证据适配器共同使用的索引步骤；保留原有
  最后一条覆盖语义。它与新证据关联工具的严格重复检查有意区分。
- `event_timeline.set_runtime_timeline_event`：从旧适配器提取的同一份 timeline 写入
  实现，近期课程绑定直接调用；不选择对象、不改变时间或 signaling 策略。

示例（仅列出接口，不自动调用模型或生成视频）：

```python
from textbook2video.research.experiment_support import (
    freeze_experiment_inputs, sha256_file, verify_experiment_inputs,
)

manifest = freeze_experiment_inputs(
    "new-run/inputs.json",
    inputs={
        "source": "raw.txt", "propositions": "proposition_graph.json",
        "candidates": "candidate_pool.json", "method_config": "config.json",
        "source_version": "source-files-and-hashes.json",
    },
    methods={"rq1": {"research_condition": None}, "rq2": {"method": "proposed_v13"}},
    version={"commit": "recorded-commit", "dirty": True},
)
frozen_manifest_hash = sha256_file(manifest)  # 保存到独立的运行协议/版本记录中
verify_experiment_inputs(manifest, expected_sha256=frozen_manifest_hash)
```

这里不自动发现或读取 gold，不扫描父目录寻找候选，不自动启用任何研究方法。
调用者仍负责显式列全实际消费的输入；dirty 状态需固定源码文件，不能只保存 HEAD。

## 研究方法和生成流程保持不变

普通 produce 仍按教材/讲稿/Storyboard → 配音 → HTML → 录制/合成执行。
近期 RQ1 与 Visual Agent 保留原决策、生成、审核、修订、SVG 编译和课程接纳路径。
RQ2 仍由 course_binding 显式选择 Direct 或 Proposed v1.3，之后通过实测音频和
现有 dynamic_planner 形成多对象事件。RQ3 继续保留执行与最终画面观察的区别。

原有 `binding_methods.bind_lexical`、`bind_embedding`、默认参数的
`bind_source_conditioned` 继续提供独立对照；Proposed v1.3 仍要求其原有上下文、
图像和语义审核参数。没有把来源关联基线偷偷替换成 v1.3，也没有增加包装方法。

来源和命题准备原本已共用 source_evidence/proposition_graph；普通课程的 partial、
clause、组件充分性选项与旧入口不同，因此没有强行合并参数或增加新编排层。
普通 RQ1 的 research_condition=null 和素材 USED_WITH_WARNING 都保持原意。

## 旧入口的用途

`--p0-research` 及 p0_integration/p0_method_runner 保留为历史实验兼容入口。
原有开关、校验、strict 策略、产物命名和 schema 不变；历史 bundle 验证仍在旧
适配器中执行，不能直接套到近期 development 素材上。
`_set_runtime_timeline_event` 是旧参数名转发，保留 `research_p0` JSON 字段。

这个 worktree 没有另一分支中的 prepare_p0_research/schedule_p0_research；
本轮标记的是这里真实存在的旧编排，不从另一分支复制一套适配器。
新研究不需要开启旧开关；完整删除仍需迁移外部脚本和历史调用方，留待后续。
