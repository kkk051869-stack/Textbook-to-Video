# 交付与合并清单

## 每个人提交前

- [ ] 分支基于同一 G0 starter commit；
- [ ] 没有提交 `.env`、密钥、缓存、虚拟环境或临时视频；
- [ ] 没有修改 frozen mock v0.1；
- [ ] 新数据写入新的 run ID；
- [ ] schema 校验通过；
- [ ] 单元测试通过；
- [ ] 模型、Prompt、配置和 input/output hash 已记录；
- [ ] 失败和 abstention 没有被过滤；
- [ ] result bundle 含 README。

## A 交给 B

- [ ] knowledge proposition ID 集合；
- [ ] visual-support/acquisition prediction；
- [ ] 候选视觉及其 provenance；
- [ ] source refs；
- [ ] confidence/abstain reason；
- [ ] run manifest 和 hash。

## B 交给 A/论文汇总

- [ ] narration proposition→element binding；
- [ ] visual event schedule；
- [ ] target resolution/runtime status；
- [ ] render evidence；
- [ ] early/late/missing/wrong-target 等指标；
- [ ] run manifest 和 hash。

## G1 只合并

- dry run 发现的问题；
- 正式标注协议；
- 20–30 proposition pilot gold；
- 仍保留或删除的标签；
- 必要的 versioned migration。

不在 G1 临时加入 AI 补图、通用 RAG、repair loop 或 layout optimization。
