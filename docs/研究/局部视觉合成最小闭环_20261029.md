## 显式入口

```python
from pathlib import Path
from textbook2video.pipeline.course_visuals import compose_local_visual

result = compose_local_visual(
    segment,                         # 已有 segment，成功才原子提交
    revision=Path("existing/revision"),
    asset_id="existing-visual-id",    # 已有 execution_assets 清单中的唯一 SVG
    output_dir=Path("new/local-insert"),
    images=retained_image_paths,      # 可选：既有 {segment_id:element_id -> 本地图片路径}
    storyboard_path=source_storyboard, # 可选：完整故事板及相邻 images/ 的持久化来源
    theme="dark-blue-academic",
    browser="msedge",
)
```

不传 `replace_element_id` 即纯插入，追加到原 elements 末尾，不改变旧 ID 或事件。需要替换时显式增加：

```python
replace_element_id="body",
coverage={
    "element_id": "body",
    "decision": "represented",
    "fact_quotes": ["水受热蒸发"],
    "visual_refs": ["water-cycle:evaporation"],
    "source_evidence": "水受热蒸发。水蒸气遇冷凝结。",
    "reason": "原文事实完整呈现在所引用节点中",
},
```

`coverage` 复用原有结构、`visible_facts`、`apply_visual_page_plan` 的事实逐字枚举、引用存在性和 `exact_evidence` 校验。额外在浏览器检查事实确实出现在所引用 SVG 节点的可见文字中；引用整幅资产时检查整图。不能用 omission decision 删信息。

默认只消费已有 strict review 通过且与 revision 绑定的资产；调用 `verify_revision` 检查原文、请求、规格、资产、父链及既有审核绑定。未审核资产必须显式 `engineering_fixture=True`，审计状态仍是工程夹具未审核，不会伪装成语义通过。该参数不调用或模拟审核。

首版仅支持 SVG。替换对象限 `text/quote/badge`，不替换图片、标题、组件或几何对象；这些需要后续对象映射。替换在原位置放入新 ID，避免影响其他位置别名。默认新 ID 由 segment、asset ID/hash 与所选目标确定，不依赖元素顺序；显式 ID 也可用，冲突或复用已归档删除 ID 时拒绝。

## 保全与失败处理

- 未修改元素的字典值（含内容、ID、来源）原样保留；旁白、时长与事件不重建。
- 替换前检查 `target/target_image/image_id` 依赖；有 overlay 或其他元素依赖时拒绝。
- 只允许对单一替换目标的普通 show 入场事件改目标；拒绝分组、stagger、highlight/hide/focus 等动作，以及 show 搭配 highlight/pulse/fadeOut/drawPath/growBar/legacy 等效果。不存在多对象合并到整图的映射。
- 页面、被替换元素或命中事件有已知研究绑定时拒绝替换，不修改冻结契约或研究 sidecar。
- 对 timeline 与 animations 分别比较编译结果，包括非活动 legacy fallback。除明确替换对象的 target/selector 外，事件 ID、行为、效果与全部时间字段必须相同；无关事件原始表示也不重写。
- `local_visual_operations` 仅为工程操作审计：保存原对象全文、coverage、被改目标事件的原记录、输入 segment hash、revision/source/asset 路径与 hash、图片清单、布局报告位置。它不是第二套 visual_element/event/schedule/trace，也不是研究标注。
- 在 deepcopy 上规划、渲染、双视口检查，复查资产 hash 后才更新调用者 segment。失败保留诊断输出，原页面不变；失败目录没有成功的 segment.json，不可据其中 HTML 宣称操作通过。
- 输出目录必须不存在；失败时不留下可被误认成成功的 `storyboard.json`，但保留布局诊断供排查。HTML 内嵌图片，避免 HTML 预览依赖可变文件。成功时保存完整 `storyboard.json` 和 `images/`；每张图在 `metadata.course_visuals.assets` 与页面操作的 `asset_inventory` 中有相对路径及 SHA-256。`load_local_storyboard_page()` 只用保存后的路径和清单即可校验并重载，不依赖本次返回的图片映射、源临时目录或旧工作区路径。

## 布局与动画

局部模式保留原正文与组件，不走内容压缩。沿用既有图文和图集布局；局部页面同时包含双图和流程组件时，选用已有横向箭头流程与胶囊要点变体，并缩短图文间距。新增 SVG 按自身 viewBox 比例呈现，不强制统一图框。带标注原图按真实图片比例形成容器，标注百分比继续针对实际图片像素；标注越出图片边界时不再被图片容器裁掉。

实际浏览器在 1600×900 与 1366×768 分别检查所有 ID、正文事实、图片加载、视口与祖先裁剪、自然内容高度、SVG 字形边界及投影字号。SVG 文字下限为实际显示 16px；正文/既有小标注检查下限为 12px。局部 fit-scale 禁止整体缩小；空间不足返回调整/拆页错误，不删正文、不截断、不自动缩字。

静态 HTML 强制全显只用于几何验证。runtime.html 则编译现有 timeline，使用原 controller 和原 animationTrace；预览入口在 controller 初始化之前提供时间轴，不修改正式录制控制器。局部样式补齐 overlay show 的基础终态，防止后续 highlight 恢复 scale(0.8)/opacity:0，仍允许原动画执行。
