# S2 生成器：拓扑与渲染器匹配修正

2026-11-11。本轮仅离线工程修正，模型、图片生成 API、TTS、录制调用均为0；未改 Proposed 或语义审核规则。

## 修改

原模型扁平图选择 relationship，但提出的有向图超过专用三阶段模板，执行器直接拒绝。现在 `visual_model_interface.renderer_graphs()` 在自动接口中先核对显式拓扑：

- 兼容三阶段、单中间节点时，继续使用原 relationship 渲染器。
- 其他合法 DAG 可显式转交现有 flow 渲染器，保留全部节点、ID、连接、方向、文字、角色及来源引用；选择记录写入现有 interface_changes，不默改原始回复。
- 循环、自环、重复或缺失 ID/边、无向边、关联/比较等非方向关系不自动转为流程。
- constraint、金额/value、accent、显式列和其他不能保证原样展示的字段继续拒绝，不通过丢字段完成转换。
- 原手工/既有 diagram 容器仍保持权威，不自动改写其模板或布局。后续来源、角色、容量和几何门禁不变。

`visual_tools.ASSET_PLAN_RULES` 同步说明执行器可审计选择兼容渲染器，仍要求模型优先选择适当形式，不允许改造教学内容来适配模板。不是新生成器、Schema 或 Agent。

代码：`src/textbook2video/research/visual_model_interface.py`、`visual_tools.py`；新增 `tests/test_visual_renderer_routing.py`。
