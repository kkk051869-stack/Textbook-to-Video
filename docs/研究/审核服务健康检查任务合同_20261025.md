# 审核服务健康检查任务合同

目标：分离文本规划模型与图片审核模型；增强前用一次最小图片理解请求验证审核服务。失败停止整个增强批次，不逐页重试公共故障，不计作页面内容不合格或增强成功。

范围：普通课程入口、预览入口、模型参数透传、健康检查模块及相关测试。保持已有逐页事务和审核标准。默认审核模型仍为规划模型；使用 ecnu-max 必须显式指定，运行证据记录实际模型。

验证：离线测试成功、协议错误、服务异常、批次提前停止和模型透传；真实服务仅做最小图片健康请求。不跑整课、不跑正式实验。独立只读复核后汇报。

已知证据：本机最小请求中 ecnu-plus 文本成功、PNG/JPEG 图片返回 500；ecnu-max PNG 成功。这只说明测试当时的路由表现，不证明服务端根因，也不代表课程图片审核通过。

后续独立任务：引用/布局接口、跨运行缓存、录制时钟与真实视频帧验收；本合同不宣称已解决这些问题。
