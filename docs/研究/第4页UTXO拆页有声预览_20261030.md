# 第4页 UTXO 拆页有声预览（2026-10-30）

## 结论

本轮把第4页拆成三段，使用原始旁白分段、本机中文 SAPI 配音、现有 UTXO SVG、正式页面渲染链、原控制器事件及 Chromium 录制/FFmpeg 合成，产出一段约 25.6 秒的有声开发预览。双视口静态画面、运行时事件和视频关键帧均已检查。

**第4页仍未通过恢复验收。** 冻结 storyboard 中的教材图 `e8` 及其 hash 仍被保存，但严格渲染器因没有可绑定的语义审核记录而不把它绘入最终 HTML/MP4。没有绕过来源审核门禁；该图不在最终视频中。UTXO SVG 的历史模型截图审核为 `ACCEPT`，人工状态仍为 `NOT_REVIEWED`。本环境无法接收音频输入，因此没有声称已经连续听完短片。整页语义和人工审核、全课验收均未完成。

## 事件与时间核对

浏览器 runtime trace 共 10 条事件，**已提交给浏览器的事件10/10状态为 `executed`**。这不是源事件完整率：原 `e8` 的 `fadeIn` 虽仍在派生 storyboard 内，但未进入runtime，因为其图片未通过来源语义门禁。其余已编译的原目标仍各自指向原元素；新增 SVG 的事件目标仅为 `local-visual-018b0bbb891a4a10`。输出段 SVG 的计划页内时刻为 6.320 秒，实测 6.344 秒。相对于整段片长约 14.240 秒时进入输出页，截图在全片 19.8 秒时尚未展示新图、20.7 秒处于淡入、23.0 秒已经完全可读且距片尾约 2.6 秒。

上述时刻沿用现有 legacy 句子/文本匹配时序，**不构成命题级或句内动作对齐**。静态布局图只用于字号、位置与溢出检查；事件执行依据 runtime trace，实际出现时机依据最终 MP4 帧，三者没有相互替代。
