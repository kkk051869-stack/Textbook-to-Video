## 4. 代码证据与需要继续查的原因

已确认：

1. `visual_synthesis.py` 的 `_svg_document` 使用 `#f8fafc` 背景，`_box` 使用固定浅蓝配色和 21px 字号；没有接收页面 theme 参数。第 2 页的浅底 SVG 确实未与深蓝主题统一。
2. 同页分镜同时包含 `flow_step` 与 `distributed-ledger-flow` image，视频中两者都出现。重复表达从输入内容层已经存在，单改 CSS 无法解决。
3. `variants` 中已经有流程、比较、图文等布局；当前六页大量输入为 `icon_group`。缺少关系信息时，渲染器很难凭标签列表可靠恢复结构、分支或因果。
4. 第 3–7 页的分镜均带教材图引用，但本次 HTML DOM 检查没有找到这些页的 img。代码存在源图视觉语义审核门禁；图片未呈现的确切原因还需逐页核对库存、审核状态与加载记录。不能为了补画面直接放开门禁，也不能把同一教材图重复用于不相关概念。

仍未证明：

- 图像模型本身的场景插画质量。本轮没有新的 `ecnu-image` 成功产物可作代表。
- 独立层级图、比较图、统计图的实际课程效果。本轮没有对应的现成页面，不人为补造“旧图”。
- 全部页面和全部动画时刻的可见性。抽帧只支持所列时刻。
