## 实现

- `visual_compact_review.py`：程序建立面板、旁白单元、实际边、可见文字、五项关系问题和替换内容的固定 ID 清单。审核模型只返回 ID、状态、短理由和可选的证据/来源 ID；端点、标签、方向、选择器和已有来源摘录由程序从当前候选恢复，再进入原有来源、事实、关系和覆盖校验。遗漏、重复、未知 ID、跨面板证据仍拒绝。
- 协议补答仍只有一次、仍看同一组像素；部分合法负面判断进入旧有 `merge_findings`，不能因其他字段有错而丢失，也不补造缺少的正面判断。原始模型响应单独保存。旧 canonical 手动接口仍走原有完整校验。
- `visual_semantic_graph.py`：沿用 nodes/edges 接口，新增显式节点角色、关系类型及 stored_by/refers_to 对象选择。程序校验主体/动作/对象角色兼容并输出动作标签；把明确选择的保存者和所指对象写入可见正文。不存在的对象、冲突动作标签、把不可逆性质当动作等拒绝。没有多加一轮模型规划，也不推断原文没说的主体。
- 规划请求已接入新契约；直接派发、来源校验、SVG 生成以及原有局部 label/detail 修改约束保持。新模块加入代码指纹，旧版本缓存不能当作新实现的验收。
- 这只是结构表达与审核协议改进；引用有效不等于语义蕴含，节点角色选择仍可能错误，必须实际看图复核。
