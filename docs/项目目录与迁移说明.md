|---|---|
| `output/` | 普通生成默认输出，命令行为不变 |

## 历史路径与复现

迁移记录位于 `.local/backups/root-consolidation-20261117/`：

- `states-before.json`：原 worktree、提交和完整 Git 状态。
- `files-before.json`：外部目录文件的原路径、字节数、SHA256；链接只记录目标，不遍历目标。
- `moves.json`：依次发生的实际移动，可组合解析多次移动的路径。
- `files-verification.json`：迁移后逐文件校验结果；环境修复及 Python 缓存变化需单独分类。
- `environment-originals/` 和 `original-environment-links/`：修复前配置、启动器和历史链接记录。原链接可能仍指向已迁出的旧路径，仅作历史记录，不作为运行入口。

冻结实验原件没有批量替换路径。f11/e01 等历史文件内仍可见原绝对路径，这是原始记录，不代表外部项目目录仍存在。读取时可使用只读适配工具：

```powershell
# 查询旧路径的新位置及是否存在
& .\.venv\Scripts\python.exe scripts/resolve_project_paths.py --path '旧绝对路径'

# 输出派生 JSON 视图，不覆盖原清单；原哈希继续指向原文件
& .\.venv\Scripts\python.exe scripts/resolve_project_paths.py --json '.local/runs/e01/protocol.json'

# 仅生成路径适配脚本副本，不执行；目标文件必须不存在
& .\.venv\Scripts\python.exe scripts/resolve_project_paths.py --script '.local/runs/e01/evaluate.py' --output '.local/backups/e01-relocated.py'

# 历史 HTML 包含旧绝对资源路径时，在原文件旁生成可查看副本
& .\.venv\Scripts\python.exe scripts/resolve_project_paths.py --html '.local/runs/flows08-inserted-video-20261115-02/lesson.html' --output '.local/runs/flows08-inserted-video-20261115-02/another.relocated.html'
```

派生视图不是原冻结清单，不能以它的新字节代替原 manifest hash。适配工具处理文件路径字段、明确的路径字面量和标准 file URI，不自动修复任意二次编码路径或运行时拼接的路径，也不隐式修改第三方加载器。HTML 适配副本必须放在原文件旁，保留相对资源位置；原文件及旧哈希不变。相对图片路径仍以原产物目录解释，不能把派生 Storyboard 随意放到缺少 `images/` 的目录。任何实际复现实验应使用冻结源码和依赖，重新记录适配路径及运行配置；不能把当前工作区重跑结果冒充历史原结果。
